# ЖелезоЧек

**Бесплатная портативная программа для проверки б/у компьютера и комплектующих перед покупкой.**
Вставил флешку в ПК продавца → 10–40 минут автоматических тестов → понятный вердикт:
**«Брать»**, **«Торговаться — вот причины»** или **«Уходить»**.

Открытый исходный код, лицензия **MIT**. Все функции доступны всем, без ключей и активации.

> Код пакета — `hwcheck`.

---

## Скачать

Windows 10/11 (64-бит), около 200 МБ после распаковки:

- [Последний релиз на GitHub](https://github.com/BagroDeRose/zhelezocheck/releases/latest)

Распакуйте архив целиком на флешку и запустите `ЖелезоЧек.exe`. Проверьте SHA-256 архива
(указан на странице релиза) — так вы убедитесь, что файл скачался целиком и не подменён.

## Зачем это нужно

Новое железо дорогое, поэтому видеокарты, процессоры и готовые ПК массово покупают с рук.
Покупатель на встрече обычно:

- не знает, какие тесты запускать и сколько ждать;
- не умеет отличить нормальную температуру от перегрева;
- не может проверить, что видеокарта не перепрошита после майнинга и вообще та, за которую её выдают;
- торопится, потому что продавец стоит рядом.

ЖелезоЧек делает всё это сам: собирает сведения о железе, прогоняет тесты под нагрузкой,
сравнивает с эталонными данными и объясняет результат простым языком.

## Что проверяется

| Компонент | Что делает программа | Что ищет |
|---|---|---|
| **Видеокарта** | Определяет реальную модель по PCI ID, читает версию BIOS (NVIDIA), прогоняет тест видеопамяти, следит за температурами, частотами и вентиляторами под нагрузкой | Подделку (переклеенная модель), ошибки видеопамяти, перегрев, троттлинг, изменённый BIOS, изношенные вентиляторы |
| **Процессор** | Нагружает все ядра, кроме одного, с пониженным приоритетом, следит за частотами | Падение частот под нагрузкой (перегрев, высохшая термопаста), нестабильность |
| **Оперативная память** | Быстрый тест паттернами в пользовательском режиме | Ошибки чтения/записи, несоответствие объёма заявленному |
| **Накопители** | Читает S.M.A.R.T. (через smartctl или средства Windows) | Переназначенные сектора, износ SSD, наработку часов, ошибки |
| **Система** | Журнал событий Windows за 30 дней | Аппаратные ошибки WHEA, внезапные выключения, синие экраны |
| **Ноутбук** | Отчёт о батарее, тест экрана, тест клавиатуры | Износ батареи, битые пиксели, нерабочие клавиши |
| **Проверка объявления** | Разбирает текст объявления, который вы скопировали из любого браузера (или сохранённую страницу), ещё до встречи | Тревожные признаки в тексте, цену относительно рынка, несоответствие заявленного реальному железу |

## Как это работает

1. Скачайте архив и распакуйте его на флешку.
2. *(Необязательно)* Дома, ещё до встречи, скопируйте в обычном браузере текст объявления
   (название, цену, описание — или всю страницу: Ctrl+A, Ctrl+C) и вставьте его в разделе
   «Проверка объявления». Программа покажет тревожные признаки, цену относительно рынка и
   запомнит, какое железо заявлено. Встроенного браузера в программе нет — она ничего не
   загружает из интернета.
3. На встрече вставьте флешку в ПК продавца и запустите `ЖелезоЧек.exe`.
4. Выберите режим: **Быстрая проверка** (~10 минут) или **Полная** (~30–40 минут).
5. Получите вердикт с причинами и отчёт HTML/PDF, который сохранится **на флешку**.

### Принципы

- **Ничего не устанавливает на чужой ПК.** Никаких драйверов, служб, изменений реестра и
  системных настроек. Все данные и отчёты пишутся только в папку программы на флешке.
- **Ничего не записывает на диски продавца.** Проверка накопителей только читающая.
- **Работает без интернета. Ничего о вас не собирает.** Нет телеметрии, аккаунтов и отправки
  данных: программа работает полностью офлайн, всё остаётся на вашей флешке.
- **Честно говорит, чего не смогла проверить.**
- **Защищает железо.** Тест прерывается, если температура подходит к опасной границе.

## Ограничения

Ни одна программа не даёт 100% гарантии. Подготовленный продавец может временно скрыть некоторые
проблемы. ЖелезоЧек сильно снижает риск, но не заменяет здравый смысл: проверяйте продавца,
договаривайтесь о гарантии, не переводите деньги заранее.

- Только Windows 10/11 (64-бит).
- Для части проверок (S.M.A.R.T., журнал событий) нужны права администратора — программа
  попросит их и продолжит в ограниченном режиме, если их не дали.
- Версия BIOS видеокарты сверяется полностью только для NVIDIA; для AMD и Intel — частично.
- Температуру самого процессора Windows без специального драйвера не отдаёт; перегрев
  проверяется по снижению частоты под нагрузкой.
- Тест памяти — быстрый, он не заменяет многочасовой MemTest86.
- Программа не подписана цифровым сертификатом: Windows SmartScreen при первом запуске покажет
  предупреждение («Подробнее» → «Выполнить в любом случае»).
- Если флешка защищена от записи, проверка работает, но отчёты и история не сохраняются.

> **Нагрузка на железо.** Полная проверка создаёт высокую нагрузку на процессор, видеокарту и
> память. Запускайте её только с согласия владельца компьютера и на исправном охлаждении.
> Программа поставляется «как есть», без гарантий (см. [LICENSE](LICENSE)).

## Для разработчиков

### Стек

- Python 3.12+ (проверено также на 3.13), PySide6 ≥ 6.9 (Qt 6; нужны QtWidgets и QtSvg)
- pytest, ruff, pyright
- PyInstaller (портативная сборка onedir)
- SQLite (история проверок), Jinja2 (отчёты)

### Запуск из исходников (Windows)

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
powershell -ExecutionPolicy Bypass -File scripts\setup_vendor.ps1   # memtest_vulkan и smartctl
.venv\Scripts\python -m hwcheck                          # графический интерфейс
.venv\Scripts\python -m hwcheck --demo mining_gpu        # на демо-сценарии, без реального железа
.venv\Scripts\python -m hwcheck.cli collect              # сбор сведений о железе в JSON (только чтение)
.venv\Scripts\python -m hwcheck.cli run --short          # короткие (по 30 с) нагрузочные тесты
.venv\Scripts\python -m hwcheck.cli verdict --demo dying_hdd   # вердикт по демо-сценарию в консоли
```

Демо-сценарии: `healthy_gaming_pc`, `mining_gpu`, `fake_gpu_relabel`, `overheating_cpu`,
`dying_hdd`, `worn_ssd`, `laptop_worn_battery`, `ram_errors`.

### Тесты

```powershell
.venv\Scripts\python -m pytest -q
.venv\Scripts\ruff check .
.venv\Scripts\ruff format --check .
.venv\Scripts\pyright
```

Тесты не требуют реального железа: все сборщики данных проверяются на записанных образцах вывода
(`tests/fixtures/`), а тесты под нагрузкой — на фейковом бэкенде.

### Сборка

```powershell
.\scripts\build.ps1
```

Результат — папка `dist\ЖелезоЧек\` для копирования на флешку. Скрипт проверяет контрольные
суммы сторонних программ и запускает самопроверку сборки (`ЖелезоЧек.exe --demo --smoke-test`).
Релиз собирается скриптом `scripts\release.ps1`.
