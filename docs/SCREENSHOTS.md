# Как выглядит программа

Скриншоты сделаны в демо-режиме на учебных данных (данные не настоящие) скриптом
`scripts/make_screenshots.py`. Версия 2.0: программа бесплатная, все функции доступны всем.
Набор пересоздаётся целиком при каждом изменении интерфейса; имена файлов без номера версии.

## Иконка программы

Из фирменного аватара (`docs/brand/avatar.png`): 48–256 px — сам аватар, 16–32 px — упрощённый
вариант без свечения и мелких деталей. Собирает `scripts/make_icon.py`.

![Иконка во всех размерах](images/icon_sizes.png)
