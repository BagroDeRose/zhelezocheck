# Карта проекта

Для каждого файла и папки — одна строка: что это и зачем. Обновляется при появлении новых файлов.

| `packaging/hwcheck.spec` | Настройки сборки PyInstaller (папка с exe, иконка, без лишних модулей Qt) |
| `packaging/launcher.py` | Точка входа собранной программы |

| `scripts/make_icon.py` | Рисует иконку программы |
| `scripts/check_no_traces.ps1` | Проверка «без следов»: сборка не пишет в %APPDATA%, %LOCALAPPDATA%, %TEMP% |
| `.github/workflows/release.yml` | Сборка и черновик релиза на GitHub по тегу v* |
| `docs/archive/site/index.html` | Лендинг для GitHub Pages (без внешних скриптов); ссылки ЗАМЕНИТЬ-… заполняет владелец |
| `docs/archive/site/images/` | Скриншоты и иконка для лендинга (архив) |

| `scripts/` | Скрипты разработчика и выпуска (не входят в программу) |

| `scripts/release_tools.py` | Помощник выпуска: версия, имя бота, проверка папки программы, архив и SHA-256, текст релиза |
| `scripts/third_party.py` | Список сторонних Python-пакетов сборки с лицензиями (из установленных пакетов) в `packaging/THIRD_PARTY_NOTICES.md`; проверка, что нет GPL/AGPL без исключения и неизвестных лицензий (SPEC 1.4, 30.3) |
| `scripts/make_icon.py` | Иконка программы из `docs/brand/avatar.png`: многоразмерный ico (16–256 px, маленькие — упрощённые), превью `docs/images/icon_sizes.png` (SPEC 1.5, 36.1) |
| `packaging/ПРОЧТИ.txt` | Шаблон «ПРОЧТИ.txt» для архива (как запустить, как получить Pro, имя бота) |
| `packaging/exe_metadata.py` | Свойства ЖелезоЧек.exe (CompanyName, LegalCopyright — только BagroDeRose, версия) для PyInstaller (SPEC 1.5, 34.7) |

|---|---|

| `hwcheck/collectors/board.py` | Сборщик: материнская плата |
| `hwcheck/collectors/gpu_generic.py` | Сборщик: видеокарты любого производителя (WMI, коды PCI, объём памяти из реестра — только чтение) |

| `hwcheck/backends/windows.py` | Реальный бэкенд: запускает все сборщики параллельно, сбой одного не ломает остальные |
| `hwcheck/knowledge/` | Справочные знания о железе |
| `hwcheck/knowledge/pci_ids.py` | Поиск названия чипа по кодам PCI |

| `hwcheck/stress/ram_quick.py` | Быстрый тест ОЗУ узорами (нули, единицы, шахматка, бегущая единица, адрес в ячейке) |

## Как данные проходят через программу

1. Сборщики (`collectors/`) читают сведения о железе и складывают их в `HardwareSnapshot`.
2. Нагрузочные тесты (`stress/`) нагружают компоненты и одновременно опрашивают датчики; результат — список `TestResult`.
3. Правила (`verdict/rules.py`) превращают снимок и результаты в список находок `Finding`.
4. Движок вердикта (`verdict/engine.py`) решает: «Брать», «Торговаться» или «Уходить».
5. Отчёт (`report/`) сохраняется в HTML/PDF на флешку, запись попадает в историю (`storage/`).
6. Анализ объявления (`listing/`) даёт заявленные характеристики, которые сверяются с реальным железом.
