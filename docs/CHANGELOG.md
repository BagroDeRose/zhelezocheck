# Что умеет программа

До версии 2.0 программа была платной (бесплатная база + Pro по ключу); начиная с 2.0 —
полностью бесплатная и открытая. История разработки до 2.0 опущена.

## Версия 2.0.0 — бесплатная и открытая
- Программа стала **полностью бесплатной** с открытым исходным кодом под лицензией **MIT** (© 2026 BagroDeRose). Монетизация убрана: больше нет версии Pro, ключей, активации и привязки к флешке.
- Все функции доступны всем: полная проверка, подробный вердикт с аргументами для торга, графики, отчёты HTML/PDF, история, разбор объявления и тесты ноутбука.
- Из программы удалены система лицензий (привязка к флешке, проверка ключа, список отзыва, детектор перевода часов, окно активации) и генератор ключей. Окно лицензионного соглашения при запуске убрано; ответственность за нагрузку на железо описана коротко в README и LICENSE.
- Скачивание — только с публичной страницы релизов на GitHub.
- Сторонние компоненты (memtest_vulkan, smartctl и др.) и файл `THIRD_PARTY_NOTICES.md` сохранены.
