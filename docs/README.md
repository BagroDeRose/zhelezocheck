# Документы проекта ЖелезоЧек

Где что лежит — одна строка на документ.

## Главное

| Документ | Что в нём |
|---|---|
| `../README.md` | Описание программы для пользователей и разработчиков |
| `../PLAN.md` | План разработки по этапам, отмечены выполненные задачи |
| `../CLAUDE.md` | Правила работы Claude Code над проектом |
| `HUMAN_TODO.md` | **Что нужно сделать владельцу** — пошаговые инструкции |
| `CHANGELOG.md` | Что программа умеет после каждого этапа, языком пользователя |
| `DECISIONS.md` | Журнал решений, принятых без владельца: что, почему, какие были варианты |
| `PROJECT_MAP.md` | Карта проекта: каждый файл и папка одной строкой |
| `SECURITY.md` | Приватность и безопасность: программа данных не собирает, пишет только на флешку |
| `security/AUDIT_1_5.md` | Независимый аудит безопасности версии 1.5 (историческая запись) — SPEC 1.5, 37.1 |
| `brand/README.md` | Фирменный стиль: цвета, контраст с темами программы, куда положить аватар и картинку приветствия |

## Папки

| Документ | Что в нём |

| `ROADMAP.md` | Идеи развития: польза, сложность, риски, Free или Pro (ничего не реализовано) |
